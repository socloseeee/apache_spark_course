# Три карточки для проверки результата

После выполнения notebook 05 откройте Metabase и подключите ClickHouse: хост
`clickhouse`, порт `8123`, база `gold`, пользователь и пароль из вашей учебной
конфигурации. Внутри Docker имя сервиса доступно по сети; `localhost` здесь
обозначал бы сам контейнер Metabase.

Создайте SQL-запросы к таблицам без суффикса `_staging_*`. Промежуточные таблицы
содержат служебные версии публикации; они не предназначены для карточек дашборда.

## Объём успешных покупок по сегментам, RUB

```sql
SELECT segment, purchase_volume
FROM gold.volume_by_segment
ORDER BY purchase_volume DESC
```

Выберите горизонтальные столбцы. Подпись метрики — «Объём успешных покупок, RUB»:
это сумма операций `completed purchase` в рублях. По этим данным нельзя получить
прибыль или выручку банка без дополнительной бизнес-модели.

## Покупки по дням: количество и объём, RUB

```sql
SELECT dt, tx_count, purchase_volume
FROM gold.daily_purchases
ORDER BY dt
```

Начните с таблицы. В контрольном batch `2026-01-31` один день, поэтому линия
не демонстрирует динамику. Когда появятся данные нескольких дней, объём можно
показать линией; количество операций лучше вынести на отдельный график, чтобы
не смешивать рубли и штуки на одной шкале.

## Топ-5 клиентов в каждом городе, RUB

```sql
SELECT city, rank_in_city, client_id, full_name, purchase_volume
FROM gold.top_clients
ORDER BY city, rank_in_city, client_id
```

Выберите таблицу и растяните её по ширине, чтобы сумма была видна. Это пять
клиентов в каждом городе. Ранг уже рассчитан в Spark с однозначным порядком
при равных суммах; не добавляйте общий `LIMIT 5`, иначе потеряете остальные города.

Сохраните три карточки на одном дашборде. Проверьте, что сумма сегментов равна
сумме ежедневной витрины и контрольной сумме успешных покупок в Silver.
Сумма top-5 охватывает только выбранных клиентов и не должна равняться общему объёму.

В проверочном запуске 17.09.2026: 51 469 покупок, 1 288 142 925,17 RUB,
три сегмента и 45 строк top-5 по девяти городам. Для другого batch или параметров
генератора значения будут другими — проверяйте равенство итогов между слоями.
