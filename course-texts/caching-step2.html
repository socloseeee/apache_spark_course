Пометка датафрейма для кэширования

Дата-инженер собирает дорогой промежуточный датафрейм, который будет использоваться несколько раз. Он помечает его для кэширования и проверяет что пометка установлена.

Что проверяем в этом задании. Учебный модуль позволяет пометить DataFrame для кэширования и проверить is_cached. Значение True появляется сразу после пометки. В настоящем Spark данные вычисляются и попадают в кэш, когда к ним обращается действие (action); сам флаг не подтверждает, что все партиции уже сохранены. Скорость и физическое хранение это задание не проверяет.

Задание

В шаблоне прочитан transactions.csv в DataFrame df. Под комментарием # Решение:

  1. Пометьте df для кэширования через .cache()
  2. Выведите значение df.is_cached через print

Формат входных данных

CSV-файл transactions.csv: c_id (целое), amt (целое).

Формат выходных данных

Одно значение True, выведенное через print.

Подсказка
df.cache()
print(df.is_cached)
