Об авторе и о курсе

Меня зовут Богдан Рябоконь, и я Data Engineer с четырёхлетним опытом работы в крупных российских банках. За эти годы я успел поработать в нескольких топовых Российских банках — это одни самых нагруженных DWH-инсталляций в стране, где каждый день обрабатываются миллиарды строк банковских транзакций.

 Я веду tg-канал @god_given_it, где пишу про инженерию данных и реальные кейсы из российского финтеха.

Этот курс — концентрат того, что я хотел бы знать сам, когда впервые сел писать на PySpark.

Что вы сможете после практики:

  • Преобразовывать данные с PySpark. Читать данные, работать с типами, NULL, агрегатами, окнами и соединениями через DataFrame API.
  • Объяснять выполнение запроса. Читать план, распознавать shuffle и проверять пользу кэша или изменения join по наблюдениям.
  • Собрать учебный проект для портфолио. Пройти путь от сырья до витрин, проверить качество данных, историю изменений и результат повторной загрузки.
  • Поработать с настоящим стеком проекта. Spark 3.5.3 и Delta Lake, Kafka, MinIO, ClickHouse и Metabase. Полная лабораторная запускается через Docker Compose и Jupyter.

Для подготовки к техническому разговору будем опираться на ваши решения: почему выбран этот способ, где его ограничения и как подтверждена правильность данных. Заучивать отдельный банк вопросов не требуется.

Кому подойдёт курс:

  • Начинающим дата-инженерам и инженерам с опытом ETL, которые знают основы Python и SQL и хотят освоить Spark.
  • Python-разработчикам, которые хотят перейти в Data Engineering. У вас уже есть фундамент — нужно добавить инструмент для работы с большими данными.
  • Аналитикам данных, которые упёрлись в потолок Pandas. Объёмы растут, запросы тормозят, начальство просит «освоить Spark».
  • Data Scientist'ам, которым надоело обучать модели на сэмплах. Хотите готовить фичи на полном объёме данных самостоятельно.
  • Студентам технических направлений, которые хотят получить навык, котирующийся на рынке.

Кому курс НЕ подойдёт:

  • Тем, кто не знает Python и SQL — это базовые требования. Я не учу программированию с нуля.
  • Тем, кто хочет работать со Spark на Scala — здесь только PySpark.
  • Тем, кто ищет готовый рецепт «выучи это и получи 300к через месяц». Курс даст фундамент. Дальше — ваша работа: pet-проекты, собеседования, рост.
