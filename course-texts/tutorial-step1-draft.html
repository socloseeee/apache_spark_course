Шаблон и авторский тренажёр

На платформе используется авторский модуль, который воспроизводит нужную для упражнений часть PySpark API без установки Spark. Так можно сосредоточиться на преобразовании данных. Распределённое выполнение, планы и производительность изучаем отдельно в настоящем Spark.

Служебный код подключения модуля оставьте из шаблона конкретной задачи: не нужно копировать адрес загрузки из другого урока или писать его самостоятельно. Следом шаблон создаёт входные таблицы и подключает нужные объекты. Например, df — входная таблица, F — короткое имя модуля функций. Используйте имена и импорты, указанные именно в вашем задании.

Примеры входа и выхода помогают понять формат, но не заменяют условие. Не разбирайте текст входа вручную, если шаблон уже создаёт DataFrame.

Один пример: посчитать строки после фильтра

Пусть в df уже есть такие данные, а задача просит вывести число операций со значением amount > 10000:

client_idamountcategory
115000food
23500rent

В области решения:

from pyspark.sql import functions as F

result = df.filter(F.col("amount") > 10000).count()
print(result)

Ожидаемый вывод — одно число, без заголовка таблицы:

1

Имя result удобно для примеров. Сам Spark не требует такого имени: следуйте требованиям конкретного задания. Одно присваивание переменной ничего не выводит.

F.sum("amount") и F.max("amount") сами по себе задают выражение для вычисления — это ещё не готовое число. Подробно разберём их в модуле агрегаций. Сейчас достаточно различать число и таблицу.

show() выводит первые строки, а не обязательно весь DataFrame. В заданиях соблюдайте указанный формат, имена и порядок колонок. Если нужен определённый порядок строк, задайте сортировку по условию. Не оборачивайте show() в print(): появится лишний None.

Запуск и отправка

Пробный запуск помогает проверить код на доступном примере. Отправка на проверку оценивает решение на тестах задания. Успех на одном примере ещё не означает, что решение работает для других данных.

Выводите только то, что просит условие. Например, если ожидается число 1, строка Ответ: 1 или дополнительный вывод всей таблицы могут помешать проверке. Рассчитывайте ответ из входных данных, а не подставляйте число из примера.

Если ответ не принимается

  1. Проверьте имена и типы колонок. Для осмотра подходят df.show() и df.printSchema().
  2. Посмотрите промежуточный результат. Ноль строк после фильтра может быть правильным ответом: сравните условие с данными.
  3. Сверьте формат ответа и уберите отладочные print() и show() перед отправкой.
  4. Если изменили служебную часть, сначала сохраните свой код решения отдельно, затем восстановите исходный шаблон задания.
  5. Прочитайте сообщение об ошибке: оно помогает отличить опечатку, неверный тип и неподдерживаемый тренажёром метод.

В настоящем проекте результат обычно записывают в таблицу или файл. print() и show() здесь нужны для учебной проверки и осмотра данных.
