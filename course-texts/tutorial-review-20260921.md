Причина не установлена. Исходная авторская картинка включена в черновик.

| Исходная проблема | Изменение в черновике |
|---|---|
| «В каждой задаче автоматически доступны df, F, Window», «все привычные функции» | Нужная часть API; используем объекты конкретного шаблона. В примере F импортирован явно |
| Копируемый адрес загрузки с `*******` и неточное имя файла | Оставить служебный код конкретного задания; не переносить фиктивную ссылку |
| Выход count показан как таблица с заголовком | Для приведённого кода ожидается просто `1` |
| sum/max перечислены как готовые числа | F.sum/F.max задают выражения; count возвращает число, agg — DataFrame |
| result назван обязательным требованием | У Spark такого требования нет; учитывать условие задания |
| show приравнен к обычному сохранению результата в production | Различены учебный вывод, осмотр данных и запись результата проекта |
| Любой пустой filter объявлен ошибкой | Ноль строк может быть верным результатом |
| Совет печатать промежуточные данные без оговорки об отправке | Перед отправкой удалить отладочный вывод |
| Абсолюты про ASCII-вход, скрытые edge cases и прохождение константой первого теста | Формат и критерии определяются конкретным заданием; все checker этим не объявляются проверенными |

Технические формулировки сверены с официальной документацией ветки Spark 3.5:
[`DataFrame.count()` возвращает int](https://spark.apache.org/docs/3.5.6/api/python/reference/pyspark.sql/api/pyspark.sql.DataFrame.count.html),
[`functions.sum()` возвращает Column](https://spark.apache.org/docs/3.5.6/api/python/reference/pyspark.sql/api/pyspark.sql.functions.sum.html),
[`show()` печатает первые n строк и возвращает None](https://spark.apache.org/docs/3.5.6/api/python/reference/pyspark.sql/api/pyspark.sql.DataFrame.show.html).
Эти ссылки относятся к документации 3.5.6; версия учебного стека остаётся 3.5.3.

Изменение не вводит новую технологию или дополнительное обязательное задание.
После дополнительного чтения таблица вывода уточнена: в каждой строке теперь
явно показано присваивание `result = ...` перед `print(result)` или `result.show()`.
Это исключает вывод старого значения переменной при буквальном повторении примера.

убедиться в отсутствии повторов между ними и проверить отображение в режиме ученика.
