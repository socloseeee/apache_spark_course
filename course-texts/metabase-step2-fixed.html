Первый запуск Metabase

Стек поднят (docker compose up -d), Metabase живёт на порту 3000.

Шаг за шагом

  1. Откройте http://localhost:3000 в браузере
  2. Первый запуск Metabase может занять несколько минут — время зависит от ресурсов компьютера. Если страница не открылась сразу, проверьте состояние контейнера по таблице ниже
  3. Пройдите первичную настройку:
    • язык — русский или английский
    • создайте аккаунт администратора (имя, email, пароль) — запомните их, это вход в Metabase
    • на вопрос «добавить данные сейчас» можно выбрать «Я добавлю позже» — подключим ClickHouse отдельным шагом
СимптомРешение
Страница не открываетсяПроверьте docker compose ps metabase и docker compose logs --tail=100 metabase. Если настроен healthcheck, дождитесь статуса healthy; при ошибке изучите её в журнале.
Забыли пароль администратораЕсли настроена отправка писем, используйте «Забыли пароль?» на странице входа. Другой администратор может сбросить пароль в разделе пользователей. Если доступ потерял единственный администратор, воспользуйтесь официальной инструкцией восстановления через сервер для своей версии Metabase, сохранив прежнюю базу настроек. Не удаляйте volumes: вместе с ними можно потерять дашборды и данные учебного стека.

Про аккаунт: этот логин/пароль — для входа в сам Metabase (не путать с доступом к ClickHouse). Metabase хранит свои настройки в отдельной базе (volume metabase-data), поэтому дашборды переживут перезапуск контейнера.
