# Исправленная локальная редакция курса

Подготовлена на основе commit `3376cb200204bdd528355cb88e5baf167ca46a0d` в ветке
`course-corrections`. На Stepik часть правок уже сохранена; журнал находится в
`course-texts/stepik-live-changes.md`. Удалённый GitHub пока не обновлён.

## Что изменено

- Все шесть ноутбуков проекта согласованы по новым схемам и путям v2.
- Генератор воспроизводит один batch, сохраняет manifest и точные денежные строки.
  Новый batch получает другой namespace событий; одинаковый ID не используется для нового payload.
- Bronze сохраняет исходные файлы и bytes Kafka вместе с source metadata.
- Silver показывает причины отклонений, учитывает внешние ключи и запрещает произвольный
  выбор из конфликтующих событий с одним ID.
- SCD2 переписан на один MERGE с null-safe сравнением и проверками интервалов/replay.
  Удалена безусловная перезапись истории. Новый клиент обрабатывается.
- Gold использует временное соединение с историей, точные суммы и однозначный порядок top-5.
  Метрика названа «Объём успешных покупок, RUB» с явным составом операций.
- ClickHouse сначала загружает staging и сверяет с его источником число строк,
  точную Decimal-сумму и, где есть, число операций, затем переключает витрину.
  HTTP 200 проверяется также на ошибку ClickHouse; тайм-аут не вызывает слепой повтор EXCHANGE.
- Генерация, ingestion и очистка явно используют один batch_id; при новом пакете его
  меняют во всех трёх местах, при повторе сохраняют ID и параметры.
- Порты привязаны к localhost, Kafka получает volume, параметры доступа читаются согласованно.
  Python-зависимости и теги сервисов закреплены; отдельное имя Compose не смешивает volumes
  новой лабораторной со старой. Полный стек прошёл сквозную проверку; условия — в VALIDATION.md.
- Добавлен `practice_real_spark.ipynb`: короткий мост от тренажёра к Spark.
- Созданы семь PNG/SVG-схем; четыре включены в проектные ноутбуки, две —
  в практику настоящего Spark; shuffle уже вставлена в 8.4; новая схема кэша подготовлена для 8.5. На Stepik загружены три новые PNG; попытка загрузить четвёртую 19.09 завершилась ошибкой виджета.
- В `course-texts/stepik-replacements.md` находятся готовые исправления проверенных
  фрагментов, уточнение границ тренажёра и текст нового вопроса по AQE.

## Что не добавлено ученику в обязательную программу

Нет отдельного курса CI, конкурентной записи, late-arriving SCD2 или аварийного восстановления.
Базовая модель — один writer, фиксированные данные и готовые проверки. Служебный код
в `course_checks.py` и `course_storage.py` доступен для чтения, но его не нужно писать с нуля.

## Как переносить

1. Работать с этой папкой как отдельной редакцией. Сначала подтвердить запуск и проверки.
2. Перенести исправленные фрагменты на Stepik, сохранив остальной текст, настройки заданий,
   баллы и авторский стиль. Полных оригиналов всех шагов здесь нет.
3. Загрузить PNG из assets в указанные шаги; места и alt-тексты есть в illustrations.json.
4. Обновить ссылки/вложения проекта и подписи Metabase вместе с текстами, чтобы не смешать версии.
